# 🎓 RTLab1 — Классификация систем реального времени и расчёт требуемого времени реакции

Консольное приложение на C# для классификации задач и систем реального времени, расчёта временных характеристик задач, загрузки процессора и определения требуемого времени реакции.

---

## 📌 Описание проекта

Данное приложение разработано в рамках практической работы №1 по теме:

**«Классификация систем реального времени и расчёт требуемого времени реакции»**

В качестве исходной системы рассматривается:

**Вариант 2 — Бортовая система автомобиля**

Рассматриваемые задачи:

- экстренное торможение;
- контроль давления в шинах;
- управление двигателем;
- мультимедиа.

Приложение позволяет:

- классифицировать задачи по типу времени реального времени;
- рассчитывать запас времени выполнения задачи;
- проверять выполнимость дедлайна;
- определять тип дедлайна;
- классифицировать систему реального времени;
- находить критическую задачу;
- рассчитывать требуемое время реакции;
- рассчитывать загрузку процессора;
- определять архитектуру системы;
- формировать итоговое заключение.

📊 Расчётные характеристики

⏱ Запас времени

Для каждой задачи рассчитывается:

L = D - C

где:

L — запас времени;
D — дедлайн;
C — время выполнения задачи.

Условие выполнимости:

L >= 0

⏰ Тип дедлайна

Тип дедлайна определяется по соотношению D и T:

D = T → Неявный
D < T → Ограниченный
D > T → Произвольный

🔴 Классификация системы

Если в системе присутствует хотя бы одна задача класса Hard, система классифицируется как:

Жёсткое реальное время

Если задач Hard нет:

Мягкое реальное время

⚠ Критическая задача

Критической является задача класса Hard, имеющая минимальный запас времени L.

Для текущих исходных данных критической является:

Экстренное торможение

Запас времени:

L = 8 мс

⚡ Требуемое время реакции

Для расчёта используются задачи класса Hard.

При отсутствии задач Hard используются все задачи.

Для текущего варианта:

Rтреб = 10 мс

📈 Загрузка процессора

Используется формула:

U = Σ(Ci / Ti)

Для текущих исходных данных:

U = 0,50

Проверяется условие:

U <= 1

Условие выполняется.
